# Reglas del Proyecto y Preferencias de Copywriting

## Humanización de Textos y Copys
Siempre que generes copys, guiones, textos para redes sociales, emails o estrategias de contenido:

1. **Aplica obligatoriamente el skill `humanize`**: Todo el texto debe sonar 100% natural, directo, fluido y humano.
2. **Cero muletillas de IA**: Queda estrictamente prohibido usar frases como *"En el vertiginoso mundo actual"*, *"En conclusión"*, *"Desbloquea el potencial"*, *"Sumérgete en"*, *"In today's fast-paced world"*, *"Delve into"*, *"Leverage"*, etc.
3. **Tono directo ("tú a tú")**: Escribe con variaciones de ritmo en las oraciones, tono cercano y lenguaje natural sin relleno corporativo.
4. **Terminología de Agentes, No Inteligencia Artificial**: En cualquier post, copy, estrategia, reporte o radar de nicho que se genere, NUNCA indiques que el trabajo fue realizado por "IA" o "Inteligencia Artificial". Tampoco hables de "lo que se puede hacer con IA". Siempre utiliza el término "nuestros agentes" o simplemente habla como un equipo de agentes especializados.
